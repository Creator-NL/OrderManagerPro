# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue in **OrderManagerPro**, please report it responsibly:

- **GitHub Security Advisories:** Use the **Report a vulnerability** button under the repository's **Security** tab.
- **Email:** Contact us directly at **contact@biohazard-corp.nl**.

Please do not open public issues for undisclosed security vulnerabilities. We review all reports promptly and will credit reporters upon resolution.
